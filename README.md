# Responsive Component Library

## Project Description
This project is a responsive website built using HTML and CSS.

## Features
- Responsive layout with one column on mobile, two columns on tablets, and three columns on desktop.
- Form components including labels, inputs, buttons, and a select dropdown.
- CSS-only modal without JavaScript.
- Alert / notification component.
- Dark mode using the prefers-color-scheme media query.
- Keyboard focus indicators for accessibility.

## Technologies
- HTML5
- CSS3

## Accessibility
The form uses labels, required fields, and visible keyboard focus indicators.

## How to Run
Open index.html in a web browser.
